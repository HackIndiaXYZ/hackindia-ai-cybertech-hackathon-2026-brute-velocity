## Key Talking Points for Q&A

- **Why authorization-first?** "Every scan runs on user-uploaded code only. No scanning public sites, no real credential extraction."
- **How does scoring work?** "Transparent: start at 100, subtract by severity. Critical = 11.5, High = 5, etc. No black box."
- **What if NVIDIA is down?** "Automatic fallback to Groq, then Gemini, then local heuristic mode. The app always works."
- **Are secrets sent to AI?** "Never. We redact all detected secret values before sending any code context to AI providers."
- **Does it modify the original project?** "Never automatically. Patches go to an isolated temp copy and require explicit human approval."

---

## Fallback Plan

If NVIDIA NIM is unavailable during the demo:
- The UI will show "AI Engine: Local heuristic mode"
- Patches are generated using deterministic rules
- All other features work identically
- Say: "Notice the AI engine fell back to local heuristic mode — Velbrix always works, even without API keys."
